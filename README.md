# Перп-DEXы: что на самом деле накапливает участник

Сравнительный разбор трёх площадок бессрочных контрактов без обращающегося токена — **Entropy**, **Arcus**, **Nado**. Срез данных: 23 октября 2026.

**[Читать кейс (PDF)](perp-dex-rewards-case.pdf)** — 3 страницы.

## О чём

Ни на одной из трёх площадок размер вознаграждения участника не является обязательством. Раскрыт только размер распределяемого пула, и то не везде. Доля конкретного участника во всех трёх случаях определяется площадкой по её усмотрению, по методике, которая не опубликована нигде.

В кейсе: устройство трёх моделей вознаграждения, связь с традиционными финансами, собственные расчёты, реестр из 20 источников и журнал 10 расхождений между ними.

## Что посчитано самостоятельно

- **Распределение поинтов Arcus.** Выгружен лидерборд целиком: 16 705 участников, 750 000 поинтов. Среднее начисление 44,90, медиана 2,87 — разрыв в 15,6 раза. Первые 100 участников держат 40,3% пула.
- **Система уровней Arcus.** Площадка присваивает уровни, нигде их не описывая. Расчётом долей установлено, что это процентили: 50 / 30 / 15 / 4 / 1 процент.
- **Экономика деплоера Entropy.** По обороту и комиссиям за 30 дней: доходность залога около 1,3% годовых, часть оборота убыточна. Торговые комиссии не являются источником дохода деплоера.

## Воспроизведение

```
python arcus_leaderboard.py
```

Скрипт обращается к публичному интерфейсу `points-api.arcus.xyz/v1/leaderboard`, сохраняет CSV и выводит сводку по распределению. Ключи и авторизация не требуются. Числа изменятся: пул пополняется еженедельно.
